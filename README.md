# 교실 스파이 채팅 게임

학생은 QR코드로 입장하고, 교사는 방 생성 → 제시어 입력 → 스파이 수 선택 → 게임 시작을 진행하는 실시간 웹게임입니다.

## 요구 사항

- Node.js 18 이상
- 인터넷 접속 가능한 서버 (교사·학생 모두 서버 주소에 접속할 수 있어야 함)

## 로컬 실행

```bash
npm install
npm start
```

교사 브라우저에서 `http://localhost:3000` 접속, **교사용 방 만들기** 클릭.

## AWS Lightsail 실행 예시

```bash
# 프로젝트 폴더에서
npm install
PUBLIC_URL=https://your-domain.example PORT=3000 npm start
```

`PUBLIC_URL`에는 학생들이 실제 접속하는 **HTTPS 공개 주소**를 입력하세요. QR코드 주소를 생성할 때 사용합니다. 환경변수가 없으면 접속한 브라우저 요청의 주소로 생성하므로 `localhost`로 접속해 만든 방의 QR은 학생 기기에서 작동하지 않습니다.

실제 수업에서는 Nginx 리버스 프록시 및 HTTPS를 사용하세요. 기존 Lightsail Node.js 서비스를 운영 중이라면 이 프로젝트는 **별도 포트와 별도 서비스**로 실행하고, Nginx에서 도메인/서브도메인을 연결하는 것을 권장합니다. Socket.IO를 위한 WebSocket 업그레이드 헤더가 필요합니다.

```nginx
server {
    listen 80;
    server_name spy.example.com;
    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

위 내용은 **설정 예시**이며 실제 서버 환경과 도메인에 맞게 수정하고 HTTPS를 설정해야 합니다.

## 규칙

- 최소 3명, 최대 60명. 교사가 전체 참여 인원 내에서 스파이 수 설정.
- 학생은 본인에게만 **일반학생 + 제시어** 또는 **스파이 + 제시어 비공개** 역할 표시.
- 설명은 순서대로 한 명씩 입력. 제출 즉시 모든 참가자의 화면 상단에 크게 표시되며 기록에도 남습니다.
- 참가자는 진행 중 언제든 챌린지 가능. 일시정지·아웃 상태에서는 불가.
- 일반학생의 챌린지 신청은 모두 익명입니다. 스파이를 맞히면 **스파이 이름만 공개**되고 아웃되며, 성공한 일반학생에게 **라운드 종료 시 1점**을 지급합니다(진행 중 점수 변화로 신청자가 드러나지 않도록 반영 지연). 틀리면 **도전한 일반학생의 이름**이 공개되고 그 학생이 아웃됩니다. 대상이 일반학생이더라도 지목된 학생의 정체는 공개하지 않습니다. 결과는 교사 및 모든 학생 화면에 팝업으로 알립니다.
- 스파이가 제시어를 정확히 맞힘: 본인 +2점, **다른 스파이 각 +1점**(이미 아웃된 스파이 포함), 라운드 종료. 답안은 유니코드 정규화, 띄어쓰기, 대소문자를 무시하고 비교.
- 스파이가 틀리면 해당 스파이 아웃·정체 공개. **누가 제시어 챌린지를 신청했는지는 성공 시 다른 학생에게 별도로 공개되지 않습니다.** 오답 시에는 규칙에 따라 정체가 공개됩니다.
- 모든 스파이가 아웃되면 일반학생 팀의 승리로 라운드 종료.
- 교사만 게임 시작, 일시정지/재개, 차례 넘기기, 라운드 종료, 강퇴, 다음 라운드 준비 가능.
- 점수는 다음 라운드에도 누적. 라운드 재시작 시 역할과 제시어 재배정.
- 페이지 새로고침 후 해당 브라우저에서 자동 재접속하며, 학생 및 교사의 인증 토큰은 그 브라우저의 localStorage에 유지.

## 현재 버전의 제한 사항

- **서버 메모리에만 데이터 저장**: 서버 재시작/프로세스 종료 시 방·점수 초기화. 수업 중 재시작하지 마세요.
- 교사 1인, 방별 60명 권장. 장기 운영·다중 서버 구성을 원한다면 Redis/DB를 연결해야 합니다.
- 방 생성자의 브라우저에 저장된 교사용 인증 토큰이 관리 권한이므로 공유 기기와 브라우저 저장정보 취급에 유의하세요.
- 게임 시작 후에는 신규 입장 불가(기존 학생의 재접속만 가능). 다음 라운드 준비에서 다시 입장할 수 있습니다.
- 학교 현장에서 사용 전 테스트용 학생 기기 2~3대로 연결·점수·강퇴·재접속 등을 확인하세요.


## V3 추가 기능 (2026-11)

- **교사용 실시간 진행판**: 접속 인원, 생존 인원, 생존 스파이 수(교사 전용), 등록 설명 수, 현재 차례 및 최근 진행 상황을 자동 갱신합니다.
- **전체 결과 애니메이션**: 성공 시 축하 색종이·팝업, 실패 시 경고 팝업과 흔들림 효과. 기존 V2 익명 챌린지 규칙을 그대로 유지합니다.
- **라운드 종료 순위표**: 종료 시 모든 참가자에게 누적 점수순 순위표 팝업을 표시하며, 화면에도 남습니다. 공동 점수는 공동 순위를 사용합니다. 다음 라운드에서 점수는 유지됩니다.
- **효과음**: 오른쪽 위 `🔇 소리 켜기` 버튼을 눌러야 재생됩니다. 학생·교사 기기별로 활성화하며, 새 설명·도전 결과·라운드 종료 시 짧은 Web Audio 효과음이 재생됩니다. 저작권 음원 파일은 사용하지 않습니다.
- **제약**: 방/점수 데이터는 여전히 메모리 저장이며, 클라이언트 연결 환경에 따라 결과 팝업 도착과 라운드 종료 상태의 도착 순서가 달라질 수 있습니다. 실제 수업 전 3명 이상의 기기로 시험해 주세요.

## V3: 교사 진행판·효과음·캐릭터 이미지

- 교사 진행판: 실시간 접속 인원, 생존 인원, 남은 스파이 수(교사 전용), 현재 설명 차례, 최근 진행 기록 확인.
- 학생 역할 카드: 제작된 콘셉트 이미지에서 추출한 스파이/초등학생 캐릭터를 해당 역할 사용자에게만 표시.
- 챌린지: 성공 시 색종이 애니메이션, 실패 시 흔들림 애니메이션, 모든 기기에서 전체화면 결과 팝업.
- 라운드 종료: 결과 팝업 다음에 누적 개인 순위표, 메달 표시.
- 효과음: 우측 상단 ‘소리 켜기’ 버튼을 기기마다 눌러야 재생(모바일 브라우저 자동재생 제한). Web Audio API 사용, 별도 음원 파일 없음.
- 이미지 원본: 사용자 승인 하에 생성된 콘셉트 이미지를 크롭하여 `public/assets/`에 포함.

### 개인정보 및 수업 운영 주의
- 방 코드는 학생과 교사가 공유하지만 교사 인증 토큰은 브라우저 내부 저장소에 보관됩니다. 교사 화면을 빔프로젝터에 표시할 때 제시어와 스파이 명단이 보이지 않도록 주의하세요.
- 진행 중 현재까지의 점수는 공개되지만, **일반학생 챌린지의 +1점은 라운드 종료 시에만** 공개됩니다.
- 이 버전은 소규모 교실용 시범 구현으로, 운영 전 학교 네트워크와 여러 기기에서 실제 테스트를 권장합니다.


## V5: 공통 제시어 확인 버튼과 설명 완료 자동 승리
- 모든 학생에게 평상시 똑같은 `🔐 제시어 확인` 작은 버튼이 표시됩니다. 일반학생만 누르면 제시어가 보이고, 스파이는 제시어 대신 `제시어를 확인할 수 없습니다.`가 표시됩니다. 스파이에게 서버가 정답을 보내지 않는 기존 원칙을 유지합니다.
- 역할 최초 확인창은 그대로 유지됩니다. 확인 이후 일반 화면에는 역할 정보가 남지 않습니다.
- 모든 **현재 생존 참가자**가 한 차례씩 설명하면 자동으로 라운드가 종료됩니다. 중간에 아웃된 참가자는 더 이상 설명 의무가 없고, 교사의 `차례 넘기기`도 해당 학생의 설명 기회가 끝난 것으로 집계됩니다.
- 그 시점까지 스파이가 정답을 맞히지 못하면 **강퇴되지 않은 모든 일반학생(아웃된 학생 포함)**에게 각 +1점을 지급합니다. 과거 스파이 지목에 성공하여 보류 중이던 개인 +1점도 라운드 종료 시 별도 합산됩니다.
- 주의: 마지막 설명이 제출되면 즉시 종료됩니다. 스파이는 그전에 챌린지해야 합니다.

## V6: 마지막 설명 후 60초 최종 추리
- 생존한 학생들의 설명이 모두 끝나면 라운드를 즉시 종료하지 않고, **60초 동안 최종 추리 단계**로 전환합니다.
- 생존 스파이만 이 단계에서 제시어 정답을 제출할 수 있습니다. 일반학생은 관전하며 남은 시간을 확인합니다.
- 남은 시간은 교사 및 학생 화면에 동일하게 표시됩니다. 시간의 기준은 서버이며 새로고침해도 60초가 다시 시작되지 않습니다.
- 교사의 일시정지 시 타이머도 멈추며, 재개하면 남은 시간부터 이어집니다. 즉시 라운드 종료도 가능합니다.
- 시간 내 스파이가 정답을 맞히면 기존 규칙대로 정답 스파이 +2점, 다른 스파이 각각 +1점(기존 아웃 포함)입니다.
- 60초가 끝나면 스파이 정답 기회가 닫히고 일반학생팀이 승리합니다. 아웃된 일반학생도 포함하여 강퇴되지 않은 일반학생 모두 +1점이 지급됩니다.
- 생존 스파이가 한 명도 남지 않으면 기존 규칙대로 즉시 일반학생 승리합니다.

서버 가상 이벤트 검사는 `npm run test:logic`으로 가능합니다. 이는 실제 다수 기기 접속 부하 시험은 아닙니다.


## V7: 학생 자유 채팅
- 순서대로 입력하는 공식 설명창과 별개로, 모든 생존 학생이 자유롭게 사용할 수 있는 소형 공용 채팅창이 있습니다. 교사도 실시간으로 확인합니다.
- 자유 채팅 메시지는 모든 학생에게 이름과 함께 표시되며, **역할 및 제시어는 전송하지 않습니다**. 스파이 추리 챌린지 입력 내용도 자유 채팅에 공개되지 않습니다.
- 서버는 메시지를 최대 160자로 제한하고 전송 간격을 1.2초로 제한합니다. 최근 60개 메시지만 메모리에 보관합니다.
- 라운드가 끝나거나 일시정지되면 학생 채팅을 보낼 수 없습니다. 아웃된 학생은 읽기만 가능합니다.
- 자유 채팅은 게임방별로 분리되며 새 라운드 시작 때 기록이 초기화됩니다.

## V8 changes (2026-11-07)
- When all spies are caught, EVERY non-kicked regular student receives +1, including eliminated students. The same centralized award applies when the final 60-second timer expires. Team points are given once, and deferred successful challenge points remain additive.
- Round-end ranking marks the regular-student team victory point as `(팀 승리 +1)`.
- Elimination announcements use text-free `student-character.png` or `spy-character.png` above separate dynamic text showing who was eliminated. The earlier result-banner images with embedded Korean text are no longer used for eliminations.
- Existing in-memory rooms and scores reset on process restart: perform an update only between lessons/rounds.


## V10 스파이 정답 2회
각 스파이는 라운드마다 최대 2번 제시어를 추측할 수 있습니다. 1회 오답은 본인에게만 알리고 탈락/공개되지 않습니다. 2회 오답에서만 탈락 및 정체 공개가 발생합니다. 설명 중과 최종 60초는 동일한 총 2회 횟수를 공유합니다. 다음 라운드에서는 횟수가 초기화됩니다.

## V12: 내 설명 차례 팝업
- 학생 본인의 설명 차례가 오면 역할 구분 없이 동일한 안내창이 해당 학생에게만 나타납니다.
- 확인을 누르면 팝업이 닫히며 설명 입력란으로 이동합니다.
- 새 라운드에서 역할 공개창이 먼저 표시되고, 이를 닫으면 차례 알림이 나타납니다.
- 새로고침·채팅 업데이트로 동일한 차례 알림이 계속 나타나지 않도록 브라우저 탭에 기록합니다.
- 기존 스파이 배정·점수·익명 챌린지 동작은 변경하지 않았습니다.
